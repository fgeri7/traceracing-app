# DrawRace Inspired — Prototype 01

A saját, DrawRace 2 által inspirált játék első technikai prototípusa.

## MVP
- érintéses / egérrel történő pályarajzolás
- a rajzolás sebességéből származó sebességprofil
- a megrajzolt ív automatikus végrehajtása
- turbo
- alap telemetry
- saját, procedurálisan rajzolt pálya

## Futtatás
Ez egy statikus webes prototípus. Nyisd meg az `index.html` fájlt böngészőben.

## Következő fejlesztési lépések
1. Valódi pályageometria és pályahatárok
2. Fizikai alapú autómozgás és drift
3. AI ellenfél / ghost
4. több pálya és pályaszerkesztő
5. autók, upgrade-ek és challenge-ek
6. mobilos UI
7. Android/iOS build
8. online leaderboard / multiplayer

A cél nem a DrawRace 2 assetjeinek másolása, hanem egy saját játék létrehozása ugyanazzal a rajzolós-versenyzős alapötlettel.
