Trace Racing v23

Main physics change:
- Detects genuine sharp bends from the drawn route geometry.
- Starts braking before the corner instead of only at the bend.
- Excessive entry speed causes strong longitudinal speed loss.
- A severe 90-degree attack can fall to near walking pace.
- Lateral sliding no longer counts as full forward lap progress.
- Recovery is gradual, so a bad corner costs real elapsed time.
- Preserves exact drawn route following and full-lap checkpoint validation.
